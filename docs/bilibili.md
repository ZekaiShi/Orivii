# 06 · B 站内容与截图

[教程目录](README.md) · 上一篇：[图文气泡](visuals.md) · 下一篇：[提醒与后台工作](reminders-and-work.md)

Orivii 复用 DSH 中已安装的 B 站插件。读取字幕、转写、画面和账号状态的能力，由原插件及其依赖提供。

## 1. 在正确的 DSH 配置中安装

Windows Web 用户在后端电脑的 PowerShell 执行：

```powershell
dsh.cmd plugin --profile web add dsh-bili-watch
```

Linux / macOS 使用 `dsh`。Desktop 用户在应用内安装。按 DSH 提示加载后，打开 **更多 → 设置 → 陪伴与连接** 检查 B 站连接。

字幕、音轨转写、OCR 和原视频抽帧可能需要 ffmpeg 或本地模型。安装步骤与环境要求以 [dsh-bili-watch 文档](https://github.com/Sacredbluedragon/dsh-bili-watch) 为准。Orivii 不会自动下载这些依赖。

## 2. 按需要扫码登录

连接区提供原插件的登录入口，需要登录时使用哔哩哔哩 App 扫码并确认，再检查连接状态。

Desktop、Web，以及 Watch/Scroll 插件的登录状态可能分别维护。先核对当前使用的配置；某个窗口已登录不能证明另一个后端也已登录。

普通网页请求遇到“验证码”时，优先检查原插件读取与登录，不把验证码页面当成视频正文。

## 3. 读取一个视频

发送 BV 号或链接，并说明想了解的内容：

> 看看这个视频的方法部分，结合字幕说明它用了哪些证据，并标出不确定的内容。

后台查询期间可以继续聊天，查询内容由主助手整理后带回。视频没有官方字幕时，能否转写取决于原插件的音频能力与本地依赖。

## 4. 直接拿到画面

> 把这个视频里讲到字形的画面发给我。已有截图就直接用。
>
> 这张预览看不清，请改用原视频抽帧，再解释图里的文字。

默认先查当前角色的本地图片库，再用原插件的快速预览。仅需要截图时，画面到手即发送；需要解读时，再由支持图片的模型查看。

快速预览拼图的时间可能只是估计值。需要精确画面时说明要原视频抽帧，核对返回的来源位置。缺少可靠时间的旧画面不推算精确秒数。

同一角色换聊天后仍可按 BV 号找已有截图。图片先存到本地附件库，单独显示成气泡；右下角箭头下载原图。

## 5. 区分读取和同步陪看

发 BV 号让 Orivii 读取内容，可以独立使用。**一起看** 则是默认关闭的同步陪伴预览：在 **陪伴与连接** 开启陪伴窗口，并配置可见模式的 [dsh-browser](https://github.com/anweat/dsh-browser)。

陪看只依据当前及已观看范围交流，跳过的部分不会自动成为共同经历。会员视频、无字幕内容和特定播放器需要分别验证。

| 现象 | 先检查什么 |
| --- | --- |
| 只搜到标题 | 当前后端是否启用了读取插件，是否真正执行内容读取 |
| 没字幕也没转写 | 原插件的音频、ffmpeg 与本地转写模型 |
| 截图等待很久 | 是否要求了原视频细节；普通截图先用快速预览与本地缓存 |
| 有截图但模型说看不到 | 当前模型声明的图片能力及 DSH 图片输入通道 |
| 登录后仍是验证码 | 是否登录了当前配置、当前插件；查看原插件的实际返回 |

[排错与反馈](troubleshooting.md) 中列出了提交复现时需要的信息。
