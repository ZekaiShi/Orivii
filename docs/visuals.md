# 05 · 图文气泡与交互

[教程目录](README.md) · 上一篇：[图片与外观](interaction-preview.md) · 下一篇：[B 站内容与截图](bilibili.md)

1.1.0 可以把对比、流程、图表和小型交互直接放进聊天气泡。每份内容使用统一字号、颜色和间距，长说明按完整内容块接到下一个气泡。

## 开始使用

打开 **更多 → 设置**，确认 **优先用图文解释** 已开启并保存。平时仍可自然聊天；需要比较方案、解释机制或看数据时，可以主动指定表达形式。

> 用两栏比较这两个方案，保留每项优点和适用场景。
>
> 把这个步骤画成流程图。信息缺失的部分直接标出。

关闭这个开关后，Orivii 默认用文字解释；你明确说“画个图”时仍能使用图文。

## 六类常用表达

| 形式 | 适合什么内容 | 可以这样说 |
| --- | --- | --- |
| 图解 | 结构、原理、关系 | “用图解释这几个部件怎样连接。” |
| 对比 | 两种或多种选择 | “把费用、维护和适用场景放在一起比较。” |
| 指标 | 数字、单位与关键变化 | “先给三个指标，再解释变化。” |
| 流程 | 顺序、步骤、决策 | “把安装过程排成一条流程。” |
| 图表 | 柱状图、折线图和数据表 | “用我上传的数据画折线图，保留单位和来源。” |
| 交互 | 参数、数量与结果之间的关系 | “加一个数量滑块，按单价 12 计算总价，标明演示数据。” |

图文可包含内置 Lucide 图标及 SVG 图形。滑块、开关和选项在当前页面更新数值，无需每次操作都请求模型。

## 让内容完整地接在对话里

图文的外框就是聊天气泡。内容从图形、数据或正文开始，页面式标题栏和生成说明不会占据阅读空间。

长内容按段落、独立主题或表格行继续到新气泡。表格接续时保留表头；单个图形完整显示，正常字号随窄屏换行。阅读时使用聊天本身的滚动区域。

深浅主题及自定义气泡颜色下，正文按实际底色保持对比。表达数据的色板和图表颜色保留原色。

## 什么时候生成 HTML 或文件？

普通图解使用原生图文。需要一个独立网页、脚本或可下载文件时直接说明：

> 把这份内容做成一个 HTML 文件，让我下载。
>
> 将这些记录导出成 CSV。

接着说“改成蓝色”“再加一个字段”即可继续修改。转回日常聊天后，回复恢复为自然对话。

HTML/SVG 预览沿用完整气泡布局，经过隔离处理；自由脚本和远程资源不会在聊天里执行。需要运行完整应用时，可以交给 DSH Agent 在相应工作空间制作。

## 下载与核对

图文或 HTML 气泡悬停、键盘聚焦时可以使用圆形下载按钮。保存的是原始交付文件，预览中的主题适配不会改写下载内容。

图表反映模型实际取得或用户提供的数据。演示内容应标为演示；科研与业务结论需要查看来源，图表本身不会替代真实实验或计算。
