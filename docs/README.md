## 先分清三个东西

- **DSH**：运行 Orivii 的宿主，提供模型、搜索、Agent 工具和权限。
- **Orivii**：你在左侧打开的个人助手；一个角色可以有多个聊天。
- **工作空间**：这个角色保存聊天与记忆的目录，位于运行 DSH 后端的电脑上。

同一个角色的新聊天会共享记忆；不同角色不会自动共享。安装插件不包含模型 API 额度，也不自动安装所有工具或技能。
