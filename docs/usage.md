# 02 · 让 Orivii 融入日常

[教程目录](README.md) · 上一篇：[快速入门](getting-started.md) · 下一篇：[多个 Orivii 与解锁](identities.md)

## 聊天与聊天列表

第一次点击左侧 Orivii 会打开聊天区域；打开后再次点击，可展开或收起它自己的聊天列表。右上角 **新建聊天** 用于开始一个新的话题分组。

- 同一个角色的聊天共享近期对话和历史检索，换聊天不等于清空这个角色的记忆。
- **更多 → 设置 → 当前聊天** 可以重命名或归档。归档只整理列表，不会删除共享记忆。
- 回复过程中可以继续输入和发送；消息仍按服务端处理顺序进行，不代表同时生成多条互不相关的回答。
- **停止** 用于停止当前回复；已经另外派发的工作要在相应任务入口处理，不能假定它们也一起取消。

Orivii 的聊天列表独立于普通 DSH 聊天。委托给 DSH 的工作可能有对应的原生工作会话，用来继续执行或排查结果。

## 名字、称呼与说话方式

| 想调整 | 入口 |
| --- | --- |
| Orivii 的名字 | 更多 → 设置 → 名字 → 保存设置 |
| 它怎样称呼你 | 设置 → 更多偏好 → 关于你 → 你喜欢的称呼 |
| 身份、生活背景与喜好 | 设置 → 更多偏好 → 关于你 |
| 回复长短与表达风格 | 设置 → 连接与模型 → 自定义表达方式 → 保存设置 |
| 开关角色动画 | 设置 → 角色动画 → 保存设置 |
| 使用哪个模型 | 设置 → 连接与模型 → 模型 → 保存设置 |

可以从这段表达方式开始，再按自己的喜好改：

> 平时简短、温柔，偶尔开个玩笑。讨论技术时给出清晰步骤；拿不准的事情直说，不编造我们聊过的内容。

你也可以直接在聊天中提出偏好。需要明确校正称呼等内容时，在 **关于你** 中编辑并保存；你亲自修改的字段不会被自动印象直接改回。

## 找回以前的话题

试着说「我们之前给周末定了什么安排？」。Orivii 会结合近期上下文，必要时检索过去的聊天。需要自己核对时，打开 **更多 → 查聊天记录**，输入关键词，点击 **查看原文** 或 **打开这段聊天**。

记忆不等于模型每次都读取全部历史，检索也可能遗漏。具体日期、原话或独特关键词通常比「那件事」更容易找准。不同角色的记录不会自动混在一起。

如果某条理解不准确，可在 **设置 → 更多偏好 → 数据与权限 → 管理与修正资料 → 查看聊过的重要内容** 中查看来源、修改或停用该条理解。停用理解与删除原始聊天不是同一件事。

## 需要时联网

在设置中开启 **需要时联网查资料** 并保存。DSH 还需要提供可用的联网服务；仅勾选开关不会安装搜索插件或替你配置服务。

示例：

> 核实一下这个项目最近发布了什么，优先看官方公告，给我日期和原文链接。

后台检索过程不会逐条挤进聊天，Orivii 会把结果带回来。重要数字和时效性结论仍应检查原始来源；网页登录、访问限制或工具失败都可能影响结果。

## 一句话约定提醒

不必先建立一张任务表。直接告诉 Orivii 时间和事项：

> 10 分钟后提醒我起来活动一下。

接着可以问或修改：

> 我现在有哪些提醒？
>
> 把刚才活动的提醒改到 20 分钟后。
>
> 取消刚才那条活动提醒。

创建后先核对它确认的时间与事项。涉及跨时区或“周五晚上”这类说法，给出具体日期、时区更稳妥。

**提醒送到 Orivii 的聊天中。** 需要 DSH 后端持续运行、对应角色保持解锁，并在 **设置 → 更多偏好 → 消息与安静时段** 中开启 **有事时可以给我发消息**。关闭浏览器页面本身不会锁定角色；关机、停止 DSH 或手动锁定后不能继续送达。不应将它作为紧急事项的唯一提醒方式。

安静时段用于减少日常打扰；你明确约定的到时提醒不等同于随意发来的关心消息。具体时间请在设置里核对时区。

## 把一件小事交给后台

可以先用一个独立测试工作空间试：

> 在工作空间创建一个 hello.html，内容是“欢迎使用 Orivii”。完成后告诉我文件位置。

这类工作由 DSH Agent 及其已配置的工具执行。检查 **设置 → 更多偏好 → 数据与权限 → 允许帮我在后台办事**，并在 **更多 → 工作记录** 中查看执行状态，也可点击 **停止这项工作**。遇到宿主权限请求时按任务需要处理。

收到“已交给后台”只代表提交，不能当成已完成。拿到结果后查看实际文件；复杂任务可回到对应 DSH 工作会话继续。

当前版本支持选择、粘贴和拖入图片或文件，图片单独显示，圆形箭头用于下载。模型可交付真实图片和文本、代码、CSV 等附件。Office、PDF 正文解析仍依赖额外工具；安装 Orivii 不会同时安装 Office 技能。[附件、B 站连接与外观](interaction-preview.md)

## 哪些体验还在后面？

同步陪看、网页共读和指定话题探索提供默认关闭的预览入口。陪伴需要可见的 dsh-browser 窗口；图像理解沿用当前多模态对话模型，不支持图像时使用字幕或文字。语音通话与 QQ 等外部渠道仍在 [更新计划](../UPDATES.md) 中。

## 把说明聊成图

在“设置”中保存“优先用图文解释”的选择。图解、对比、指标、流程、图表和交互使用统一气泡；普通聊天仍直接接话。需要独立网页或附件时说明文件要求，后续修改可以接着做。[图文气泡教程](visuals.md) 提供可复制示例，[提醒与后台工作](reminders-and-work.md) 说明交付与取消。
