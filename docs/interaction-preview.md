# 04 · 图片、附件与外观

[教程目录](README.md) · 上一篇：[多角色与解锁](identities.md) · 下一篇：[图文气泡](visuals.md)

本篇按 **1.1.0** 的图片、文件与外观功能说明。B 站的安装、扫码、读取与截图见 [B 站指南](bilibili.md)。同步陪伴与自主探索仍为默认关闭的预览功能。

## 图片与文件

点击输入栏的圆形加号，或粘贴图片、拖入文件，上传完成后发送。每张图片单独显示在一个气泡中，图片右侧的圆形箭头用于下载；文字说明另放。其他文件保留文件名和下载入口。

每条消息最多 4 个附件，单个文件不超过 10 MB，图片不超过 2 MB。支持 JPEG、PNG、WebP 和 GIF，动态图按图片处理。附件使用当前角色的工作空间存储和加密方式。

当前模型与 DSH 图片通道支持图像时，图片直接交给该模型。UTF-8 文本、代码、Markdown 和 CSV 可读取并生成。Office、PDF 等二进制文件可保存和下载，正文解析需要相应工具。

模型可以发送已有附件、工作空间中的图片和公开图片直链对应的真实图片；这不代表模型本身拥有图像生成能力。切换角色前先发送或移除草稿附件。

## 本地开发预览：图文气泡

以下能力尚未随 npm 1.0.2 发布。开发预览可在设置中开启 **优先用图文解释**：适合对比、流程、数据或界面说明的问题，会优先采用图文表达，日常聊天继续用短句。

可直接试：

> 用两张卡片比较这两个方案，再给一张有来源的柱状图。
>
> 做个演示：滑块调整迭代次数，实时显示位置数 × 迭代次数，并标明这是演示数据。
>
> 看看这个 BV 号，把有字形图的真实画面直接发给我。

图文采用图解、双栏对比、指标、流程、数据和交互六种固定模板，搭配内置 Lucide 矢量图标。模型填写内容，由统一组件排版；滑块、选项和开关在浏览器内更新，不会每次调整都请求模型。

日常聊天与资料查询默认直接回复。开启“优先用图文解释”后，适合图解的机制、数据和对比会优先使用原生模板；关闭后文字优先，仍可以主动要求图示。需要独立文件时可以说“生成一份 CSV”或“做个 HTML 网页”，接着说“改成蓝色”即可继续修改；转回日常聊天后恢复普通回复。

图文、HTML 和 SVG 使用与普通消息一致的聊天气泡。内容放满后按完整段落、内容块或表格行接续到新气泡，保留表头与控件联动；单个不可拆分的图形保持完整。没有比例选择器、内部滚动条或像素裁切，窄屏自然换行。

可见部分直接展示内容，省去文件名、页面大标题、页眉、页脚和生成说明。内部背景透明、不重复套圆角卡片，由气泡统一提供底色和外框。悬停或键盘聚焦时可使用圆形下载按钮取得原文件。

透明只作用于布局背景；色板等表达数据的色块保留原色。文字会按当前气泡底色检查对比度，深浅主题和自定义气泡配色都能使用。

HTML/SVG 只显示经过处理的内容；模型生成的脚本和外部资源不会执行。预览高度由内置程序根据实际内容调整，交互使用内置组件。

图片气泡紧贴图片，小图保持原尺寸，大图按比例缩至 320 × 300 CSS 像素以内，圆形下载箭头叠放于右下角。显示尺寸不改变下载原图。

B 站画面通过已安装的 bili-watch 提取，转为当前角色的附件后，由主模型查看并发送。原插件只返回文字时仍按文字处理；没有来源时间的画面不推算时间戳，预览拼图位置标为估计值。后台查询代理继续隐藏，用户只看到 Orivii 的答复和交付物。

模型可直接请求后台截帧，抽取时仍可正常聊天。保存过的画面优先从本地库直接取出，跨聊天使用；重复获取相同来源和内容会复用图片编号。普通截图取到即发送；需要解释、辨认或比较画面时再由模型看图分析。缓存图片通过附件编号交付，无需手动搬到工作空间。

首次获取默认使用 bili-watch 的快速预览通道；插件能取得预览图时，可省去整段视频的下载和解码，失败时由插件回落到抽帧。需要看清细字或使用指定间隔时，选择原视频抽帧。分 P、间隔和帧序号分别匹配，不用其他分 P 或预览图替代指定帧。

其命令行的指定时间取帧尚未暴露在当前模型工具接口中；本预览不把间隔抽帧或预览拼图说成某一秒的精确截图。首次网络读取与模型分析仍受来源、视频长度和模型响应时间影响。

## B 站连接

在当前 DSH 配置中安装并启用 [dsh-bili-watch](https://github.com/Sacredbluedragon/dsh-bili-watch)。Windows Web 版：

```powershell
dsh.cmd plugin --profile web add dsh-bili-watch
```

Linux 将 dsh.cmd 改为 dsh；Desktop 在对应应用中安装插件。按宿主提示加载后，打开 **Orivii → 设置 → 陪伴与连接** 检查状态。需要登录时点击扫码入口，用哔哩哔哩 App 扫码并确认。

提供 BV 号或视频链接后可后台读取正文、字幕、音轨转写、评论等内容。音频转写与 OCR 需要原插件的本地依赖；请按原插件文档安装 ffmpeg、转写模型或 OCR。安装 Orivii 不会自动下载这些模型。

已安装的 dsh-bili-scroll 也可通过其注册的只读工具使用。Watch 和 Scroll 的账号登录、缓存分别由原插件维护；不同 Web / Desktop 配置需分别核实。验证码、会员权限及网站限制仍可能影响读取。

## 外观与动画

在 **设置 → 外观** 中分别调整双方气泡和角色颜色。保存后按角色生效，选择“恢复主题默认”可恢复配色。圆形加号、发送与下载按钮沿用一致的反馈动画；历史消息不重播入场动画。系统开启“减少动态效果”时停止持续运动。

## 陪伴预览

在 **设置 → 陪伴与连接** 开启陪伴窗口，点击聊天区的“一起看”，填写视频或文章地址。需要可见模式的 [dsh-browser](https://github.com/anweat/dsh-browser)，不会自动修改该插件的全局设置。

画面沿用当前支持图像的对话模型；没有图像能力时依据字幕或文字交流。只采集当前授权站点，离开范围会暂停。跳过的剧情不作为共同观看记录，截图默认不持久保存。预览仍需针对实际播放器、会员内容和 Web / Desktop 环境验证。
