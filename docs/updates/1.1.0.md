# Orivii 1.1.0 · 把想法直接聊成图

2026-11-12 · [更新目录](README.md) · [安装教程](../getting-started.md) · [GitHub Release](https://github.com/ZekaiShi/Orivii/releases/tag/v1.1.0)

这次更新围绕聊天里的表达与交付：该接话时自然接话，适合图解时直接呈现图文，截图和文件则交到你手上。

## 本次重点

### 原生图文直接进入气泡

六种模板覆盖图解、对比、指标、流程、图表和交互。内置 Lucide 图标，统一字号、间距与颜色。滑块、选项和开关在本地更新数值；较长内容按完整主题、段落或表格行接到新气泡，表头跟随保留。

HTML/SVG 也使用同一套气泡外框。预览省去文件标题栏、页面页眉、页脚与重复卡片边框；内部完整展示，窄屏自然换行。深浅主题和自定义气泡底色下，正文保持可读，色板保留原色。

同时修复了 Windows 换行符造成的预览脚本校验差异，让气泡测量和完整展开在两个平台使用一致的脚本。

### 让对话回到眼前的话题

日常交流和普通查询默认用文字回复。图解使用原生模板，用户提出网页、文件或代码交付任务时才创建附件；连续修改可以接着进行，转回闲聊后恢复普通回复。

“优先用图文解释”开关真正控制图文偏好。后台查询也沿用原请求的交付方式，并接受“不用文件，直接回答”这类补充。

### B 站画面更快交付

先查当前角色的本地图片库，跨聊天复用已有画面。首次默认调用原插件快速预览；需要细字或细节时使用原视频抽帧。只要截图时取到即发送，需要解读时才调用图片理解。

来源和时间按原插件返回保留；预览拼图的估计位置与可靠时间分别说明。原插件安装、登录、转写与 OCR 依赖仍按各自文档配置。

### 图片交付更贴合聊天

图片单独成泡，小图保持原尺寸，大图等比缩到显示范围。圆形下载按钮位于右下角，下载保留原图。图片、HTML 和原生图文的文字说明可以在相邻气泡中接着说。

GitHub Release 已可安装；npm 1.1.0 尚待发布验证。

## 从 1.0.x 升级

1. 按 [数据与迁移](../data-and-privacy.md) 备份工作空间，包含隐藏资料目录和其他角色目录。
2. 在当前 Web 或 Desktop 配置中更新 **dsh-orivii**，避免同时启用两份插件。
3. 按宿主提示重新加载或重启，打开原来的工作空间并解锁。
4. 核对角色、聊天和附件，然后尝试下面的图文示例。

Windows PowerShell：

```powershell
dsh.cmd plugin --profile web add https://github.com/ZekaiShi/Orivii/releases/download/v1.1.0/dsh-orivii-1.1.0.tgz
```

Linux / macOS 使用 `dsh`；Desktop 在插件管理中添加同一 Release 地址或选择下载的安装包。离线安装包见 [Release](https://github.com/ZekaiShi/Orivii/releases/tag/v1.1.0)。

## 三分钟体验

> 用两栏比较方案 A 和 B，再用流程图说明怎么选。
>
> 做一个演示：数量滑块从 1 到 10，单价 12，实时显示总价。
>
> 把这组记录导出为 CSV，让我下载。
>
> 把这个 BV 号已经缓存的画面发给我，再解释其中的内容。

前两个示例只需可用的对话模型；最后一个示例需要已安装并配置的 B 站读取插件。
