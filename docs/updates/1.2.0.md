# Orivii 1.2.0 · 先接话，查到再回答

2026-11-21 · [更新目录](README.md) · [安装教程](../getting-started.md) · [GitHub Release](https://github.com/ZekaiShi/Orivii/releases/tag/v1.2.0)

## 先试一句联网查询

> 请查一下 Node.js 最新 LTS 版本。

Orivii 先回一句「好，我看看。」，再通过 DSH 查询公开来源。等资料回来，它会另发一条答复，你可以在这期间继续聊天。对象明确的版本、价格、公告和截止日期等问题适合这样查。如果你只说「刚才那款」，请补上产品名、项目名或链接，让查询范围更明确。

Orivii 会尝试打开搜索返回的相关网页，并区分读到的原文和只看到的搜索摘要。查不到可用资料或联网服务出错时，回复会说明目前能确认什么。要体验这个流程，需要在 Orivii 开启 **需要时联网查资料**，并在 DSH 配好可用的联网服务。

## 其他改进

- **对话时间。** Web 发送消息时会带上浏览器时区，模型请求按这个时区理解当前时间和消息发送时间。缺少有效浏览器时区时使用工作空间设置。
- **表情和侧栏。** 同一轮的阶段回应与最终答复可以各自带表情。多条事件一起到达时按顺序播放。新版 DSH 的 Orivii 入口可正常显示名称。
- **闲时补查。** 允许主动消息、留意近况与联网后，未解决的公开问题可在 2–3 小时后进入首次补查。安静时段或聊天进行中会推迟查询；出现有用的新线索时回到原聊天。[查看触发条件](../reminders-and-work.md)

## 从 1.1.0 或 1.0.x 升级

先备份 Orivii 工作空间，并确认你记得解锁密码。按宿主提示更新同一个插件。Windows 上的 DSH Web 可用 PowerShell。

```powershell
dsh.cmd plugin --profile web add https://github.com/ZekaiShi/Orivii/releases/download/v1.2.0/dsh-orivii-1.2.0.tgz
```

Linux / macOS 使用 `dsh`。Desktop 在应用内插件管理中添加同一个 [1.2.0 安装包地址](https://github.com/ZekaiShi/Orivii/releases/download/v1.2.0/dsh-orivii-1.2.0.tgz)。npm 注册表返回 1.2.0 后，也可以用 `dsh-orivii@1.2.0` 指定版本。加载新版后选择原来的资料目录，已有聊天、身份、附件和提醒仍在那里。[数据与迁移](../data-and-privacy.md)

原生图文、B 站截图复用、自然语言提醒和后台委托继续可用。同步陪看、网页共读和指定话题探索仍是默认关闭的预览功能，依赖已配置的宿主服务。
