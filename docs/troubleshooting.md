# 05 · 常见问题与排错

[教程目录](README.md) · 上一篇：[数据与迁移](data-and-privacy.md)

先记录 **Orivii 版本、DSH 版本、系统、Web / Desktop、模型名称**。下面的检查不需要发送密码或 API Key。

## 安装与启动

| 现象 | 先检查什么 |
| --- | --- |
| 左侧没有 Orivii | 是否安装到了当前使用的 Web / Desktop；插件是否启用；重启 DSH 后刷新页面 |
| `dsh` / `dsh.cmd` 无法识别 | DSH 命令行是否已安装并加入 PATH；新开一个终端。只有 Desktop 时用应用内插件管理 |
| PowerShell 提示无法加载脚本 | 使用 `dsh.cmd` / `npm.cmd`，无需为安装插件修改系统执行策略 |
| `Failed to load plugins` | 检查 Node / DSH 兼容版本、是否启用了两份 Orivii，以及完整安装后是否重启了后端 |
| `wire field "request" failed boundary validation` 或 `without inject` | 可能是前端与后端插件版本不一致，或服务尚未启动；先重启 DSH 后端，再刷新页面，检查重复插件。仍失败时提交脱敏错误 |
| Market 搜不到 | 搜索 `Orivii`、核对 AGI 探索分类；目录同步可能有延迟，可直接用 npm 安装 |

### npm 的 E404 是什么意思？

`npm view` 只是查询仓库，不会发布或安装。E404 表示该注册表没有返回你请求的包或版本，也可能是私有包权限问题。

Orivii 的正式 npm 包是 **`dsh-orivii`**，1.0.2 已发布。Windows 可以用以下只读命令检查官方注册表：

```powershell
npm.cmd view dsh-orivii@1.0.2 name version dist.tarball --registry=https://registry.npmjs.org/ --prefer-online
```

若此命令返回正确版本，而默认命令失败，检查你正在使用的 npm 镜像：

```powershell
npm.cmd config get registry
```

镜像可能未同步。可以先按 [快速入门](getting-started.md) 使用 GitHub Release 地址；不必清理全部 npm 缓存或重装整个环境。

## 工作空间与解锁

**每次刷新都要密码？**

1. 在 **设置 → 我的 Orivii** 检查解锁期限。
2. 确认刷新期间 DSH 后端没有重启，且没有在其他页面执行“锁定”。
3. 核对是否仍连接同一个后端。Web 与 Desktop 不共用解锁状态。

8 / 24 小时到期、电脑重启、DSH 退出后要求密码是正常行为。把期限调长，要到下一次密码验证后才生效。

**资料好像不见了 / 新建角色是一片空白？**

新角色本来就是独立资料。旧角色数据应到 **我的 Orivii** 中切回，或选择原来的工作空间；不要仅凭同名就当成同一个角色。恢复备份时，选择含 `.dot-memory` 的上一级目录。

**“未完成或不兼容的记忆库”？**

先停下创建操作，保留原目录。核对是否复制了完整备份、版本是否兼容。不要删掉某些文件来强行通过检查。

**忘记密码？**

没有密码无法恢复加密资料，也没有默认密码或维护者后门。请保留原数据；建立新的工作空间不会恢复旧聊天。

## 聊天、联网与提醒

| 现象 | 下一步 |
| --- | --- |
| DSH 能聊，Orivii 不回复 | 设置 → 连接与模型，核对模型并保存；从简单问候测试，记录界面错误 |
| 回复慢 | 用短问题排除网络与供应商延迟；检查是否正在检索。长历史不会全部进入每次请求，但仍可能增加处理时间 |
| 说“无法联网” | 开启并保存“需要时联网查资料”；再确认 DSH 的搜索服务确实可用。模型名字本身不代表有搜索工具 |
| 新聊天没接上刚才的话题 | 确认还是同一个角色；补充关键词或时间，用“查聊天记录”核对原文 |
| 提醒没有送到 | 让它列出已经保存的提醒；核对时间、时区、消息设置，确认 DSH 持续运行且角色未锁定；查看创建提醒的原聊天 |
| 说“已派发”，却没看到文件 | 更多 → 工作记录查看状态；到对应 DSH 任务核对工具、权限和实际产物。派发成功不等于完成 |
| 切换角色被阻止 | 先发送或处理输入草稿，等待未送达消息结束，再切换 |
| 找不到通话入口 | 1.0.2 未包含语音通话 |
| 陪伴窗口打不开 | 在“设置 → 陪伴与连接”开启预览，并安装可见模式的 dsh-browser |

## 动画与界面

角色动画可在设置中开关。系统启用“减少动态效果”、页面不可见或角色锁定时，动画会减少或暂停；这是预期行为。

升级后仍显示旧界面，先重启对应 DSH 后端，再刷新网页。仅刷新前端不会更新后端已经加载的插件代码。

## 仍然解决不了？

[提交问题](https://github.com/ZekaiShi/Orivii/issues/new?template=bug_report.yml)，尽量使用新的测试工作空间与虚构内容复现。可以按这个格式填写：

```text
Orivii 版本：
DSH 版本：
系统与界面：Windows / Linux / macOS，Web / Desktop
模型名称（不填密钥）：
复现步骤：
期望结果：
实际结果与脱敏错误：
```

公开 Issue 不适合上传真实聊天、记忆库、完整日志或任何凭据。疑似安全问题请看 [安全反馈](../SECURITY.md)。

## B 站只搜索到了标题，没有读到内容？

在当前 Web 或 Desktop 配置中安装并启用 dsh-bili-watch，再从“陪伴与连接”检查状态。字幕不足时，原插件可能需要 ffmpeg、本地转写模型或 OCR；按原插件文档安装这些依赖。Watch 与 Scroll 的登录各自维护，不能把 Desktop 的已登录状态直接当作当前 Web 的验证结果。账号未登录时使用连接区的二维码。

## 模型请求显示 INVALID_REQUEST？

先升级到 1.0.2，并确认实际运行的 Web / Desktop 配置已加载新版本。本次修复了思考模式工具往返所需的回放信息丢失；若仍失败，请提供模型供应商、版本和脱敏后的错误代码。
