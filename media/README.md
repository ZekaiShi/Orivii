# Orivii 宣传素材

- `orivii-film.mp4`：30 秒、1080p60 宣传动画，采用已经确认的 Csus4/G7 音乐版本。
- `preview.gif`：README 首屏短循环；点击观看完整视频。
- `cover.png`、`expressions.png`、`memory.png`：从同一部动画提取的封面与场景图。

动画、对话和构图为本项目制作的演示素材；它不是产品实际操作录屏，也不包含真实用户聊天。产品能力以 README 的已实现清单为准，未来计划单独列在 UPDATES.md。

音乐中的声学采样来自 [Versilian Community Sample Library](https://github.com/sgossner/VCSL)，CC0-1.0。画面使用 [Manrope](https://github.com/sharanda/manrope)，SIL OFL-1.1。相关许可保留在 `licenses/`。没有包含 Apple 的视频或音乐；项目不隶属于 DeepSeek、OpenAI 或 Apple。

本目录作为仓库宣传内容公开，不打入插件运行安装包。
