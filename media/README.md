# Orivii 宣传素材

- `orivii-film.mp4`：60 秒、1080p60 中文宣传动画，包含完整片尾标语。
- `preview.gif`：从当前 60 秒宣传片的开心表情、后台任务和片尾品牌三个片段剪辑，约 9.9 秒，760×428、20 fps。用于 README 与 DSH Market 动态预览。
- `cover.png`、`expressions.png`、`memory.png`：从同一部动画提取的封面与场景图。
- `social-preview.png`：从新版 60 秒宣传片第 59 秒品牌定格提取的 1280×640 PNG，包含完整的两行片尾标语，适用于 GitHub 仓库的 Social preview；画面居中裁切，未拉伸角色。
- `market-chat.png`、`market-memory.png`、`market-work.png`、`market-identities.png`：1.0.1 中文功能教学视频的场景截图，分别展示聊天、历史查询、后台工作与角色切换；1280×720，画面保留“界面动画示意”标记。
- 仓库根目录 `screenshots.json` 按动图、聊天、记忆、后台工作、角色切换的顺序声明市场展示素材。
- `roles.svg`：1.0.1 多角色原创矢量示意图，使用虚构角色名；不是设置界面截图。沿用角色圆环尺寸与柔和配色，文字可编辑，无外部字体或脚本依赖。

动画、对话和构图为本项目制作的演示素材；它不是产品实际操作录屏，也不包含真实用户聊天。产品能力以 README 的已实现清单为准，未来计划单独列在 UPDATES.md。

音乐中的声学采样来自 [Versilian Community Sample Library](https://github.com/sgossner/VCSL)，CC0-1.0。画面使用 [Manrope](https://github.com/sharanda/manrope)，SIL OFL-1.1。相关许可保留在 `licenses/`。没有包含 Apple 的视频或音乐；项目不隶属于 DeepSeek、OpenAI 或 Apple。

本目录作为仓库宣传内容公开，不打入插件运行安装包。
